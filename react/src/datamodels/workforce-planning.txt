Workforce Planning – API Endpoint & Response Spec
===================================================
This document lists every mock dataset consumed by the WorkforcePlanning screen
(src/screens/WorkforcePlanning/index.tsx) and maps each to a recommended REST
endpoint, HTTP method, query parameters, and the exact JSON response shape.

================================================================================
1. GET /api/workforce-planning/plans
================================================================================
Description     : Returns all active workforce plans.
Query Params    : None (or optional ?status=active&ownerId=)
Method          : GET

Response – Array<WorkforcePlan>
--------------------------------------------------------------------------------
[
  {
    "id": "wp_2026_q3",
    "name": "Q3 2026 Workforce Plan",
    "status": "active",
    "planningPeriodStart": "2026-07-01",
    "planningPeriodEnd": "2026-09-30",
    "ownerId": "u_104",
    "currency": "USD",
    "latestSnapshotAt": "2026-06-18T09:00:00-04:00"
  }
]

Type definition (TypeScript)
--------------------------------------------------------------------------------
export interface WorkforcePlan {
  id: string;
  name: string;
  status: 'draft' | 'active' | 'archived';
  planningPeriodStart: string;   // yyyy-mm-dd
  planningPeriodEnd: string;   // yyyy-mm-dd
  ownerId: string;
  currency: string;            // ISO 4217
  latestSnapshotAt?: string;     // ISO 8601 with TZ offset
}

5. GET /api/planning-snapshots
================================================================================
Description     : Returns captured snapshots for a workforce plan.
Query Params    : ?planId={planId}
Method          : GET

Response – Array<PlanningSnapshot>
--------------------------------------------------------------------------------
[
  {
    "id": "snap_2026_06_18",
    "planId": "wp_2026_q3",
    "capturedAt": "2026-06-18T09:00:00-04:00",
    "createdBy": "u_209",
    "sourceSystem": "hris"
  },
  {
    "id": "snap_2026_06_15",
    "planId": "wp_2026_q3",
    "capturedAt": "2026-06-15T18:30:00+01:00",
    "createdBy": "u_104",
    "sourceSystem": "planning-sheet"
  }
]

Type definition (TypeScript)
--------------------------------------------------------------------------------
export interface PlanningSnapshot {
  id: string;
  planId: string;
  capturedAt: string;     // ISO 8601 with TZ offset
  createdBy: string;
  sourceSystem: string;   // e.g. "hris", "planning-sheet"
}

Summary of endpoints required for the WorkforcePlanning screen
================================================================================
| # | Method | Endpoint                           | Query Params          |
|---|--------|------------------------------------|-----------------------|
| 1 | GET    | /api/workforce-planning/plans               | —                     |
| 2 | GET    | /api/workforce-planning/scenarios           | ?planId={planId}      |
| 3 | GET    | /api/workforce-planning/line-items          | ?scenarioId={id}      |
| 4 | GET    | /api/scenario-assumptions          | ?scenarioId={id}      |
| 5 | GET    | /api/planning-snapshots            | ?planId={planId}      |

All dates are ISO-8601 strings (yyyy-mm-dd or full ISO with TZ offset).
All currency values are plain numbers in the smallest currency unit
(e.g. USD cents) or whole dollars depending on your backend convention.
The mock data above uses whole-dollar integers for budgetImpact.
